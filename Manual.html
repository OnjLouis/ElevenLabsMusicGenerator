ElevenLabs Music and Sound FX Generator for Windows

ElevenLabs Music Generator is a portable Windows application for creating music and sound effects from written prompts through ElevenLabs.

Prerequisites And API Key

You need an ElevenLabs account with Music API access and sufficient credits. Sign in to ElevenLabs and open API Keys under Developers. Create a key, enable Music access, and copy the full key when it is first shown. You may set a credit limit for safety. See the official API key guide. Keep your key private; do not put it in a prompt or bug report.

First Run

  1. Open Options, Preferences.
  2. Select the API key tab and enter your ElevenLabs API key.
  3. Use Test API key to verify it without generating music or spending credits.
  4. Before generating, set your preferred Default output folder on the General tab. Also choose the default duration, variations, format, and whether to save returned lyrics and details. Choose the Model in the main window with Alt+D; the last selection is remembered.

If you leave the folder unchanged, the application creates a Music folder beside the executable. This location moves with the application.

Your API key is protected for the current Windows account and computer in the application's User folder. Enter the key separately on each computer. Do not share the User folder with anyone else.

Generating Music

  1. Write or paste a prompt into the standard multiline Prompt field.
  2. Choose the length, number of variations, and whether the result must be instrumental.
  3. Review the automatically suggested base filename. Spaces are kept. Clear it to name each music variation from ElevenLabs' returned song title; if no title is returned, the prompt supplies a fallback. The output folder is the one saved in Preferences.
  4. Press Generate or Ctrl+Enter.
  5. Review the confirmation carefully. Generation starts only after you confirm that ElevenLabs credits will be spent.

Prompt mode saves one shared text file containing your input prompt. Variations use suffixes such as _v1 and _v2. The shared prompt file is not a transcription of what was sung.

When the base filename is blank, each completed music variation uses the title returned by ElevenLabs and a two-digit sequence prefix, such as 01 - Song title.wav. The _v1 suffix is not used for returned titles. The app stores a small .titles.json batch record under Lyrics so an interrupted batch can resume without paying for completed tracks again. Keep this record with the audio and shared prompt. Title naming uses the detailed response even when saving lyrics and details is turned off.

When you move into a length or variations field, its current number is selected so that typing replaces it. Review the length and variation count in the confirmation dialog before spending credits.

If a batch was interrupted, Generate checks the existing tracks and offers to make only missing variations. The saved prompt must match, and existing WAV files must have the expected format and duration. An existing MP3's duration cannot be verified automatically, so review the confirmation carefully. If a check fails, choose a different base filename; existing tracks are never overwritten. Keep the same model and instrumental setting when resuming a batch.

Generating Sound Effects

In the main window, press Alt+D and choose Sound Effects v2 from Model. Enter a sound description of up to 450 characters, choose a base filename and variations, then Generate. Enable Sound Effects access for your API key on ElevenLabs. Test API key checks Music access only; it does not verify Sound Effects permission.

Automatic duration lets the service choose the length. Turn it off to enter 0.5 to 30 seconds. Loop sound effect requests a seamless loop. Prompt influence ranges from 0 to 1; a higher value follows your wording more closely. Sound Effects supports the app's 44.1 kHz WAV and MP3 formats. Music-only options are unavailable in this mode; switching back restores the music controls.

The prompt counter shows characters used and remaining. Typing or pasting stops at the active model's limit: 450 characters for Sound Effects, 4,100 for Music. If you switch from a longer Music prompt to Sound Effects, the full Music draft is kept separately and restored when you return to Music.

Sound effects use the same output folder as music. Each batch saves one .sfx.json containing the prompt and its settings, without lyrics files. Choose Open Prompt to reuse this file; change the base filename for a new batch. Save Prompt still saves an ordinary text copy. Resuming an interrupted batch requires matching sound-effect settings and keeps completed audio. See the Sound Effects API reference for service details.

Composition Plans And Lyrics

For Music v2 or v2.5, choose Use composition plan, then open Edit plan (Alt+P). A plan has ordered sections with a heading, duration, optional lyric lines or short musical directions, included and excluded styles, and context adherence. You can add, remove, or reorder sections. Durations can be entered to three decimal places and total no more than 10 minutes.

For example, enter Verse as the heading and put lyric lines in its Lyrics and cues field. The section is marked [Verse] when sent to ElevenLabs. For an instrumental section, use a short direction such as {instrumental piano introduction}. These instructions do not guarantee that every sung word will match exactly. Plain prompt mode accepts ordinary descriptive prose and does not require bracketed tags.

Suggest from prompt requests a draft plan from ElevenLabs without spending music-generation credits, although the request is rate-limited. Review and edit the proposal before generating. Open plan or details loads a saved .plan.json or a track's .details.json if it contains a reusable composition plan. Export plan saves a reusable JSON plan. The current plan is recovered from User\Composition draft.json. A generated batch saves one .plan.json beside the tracks for safe resumption.

Plan mode uses section durations rather than the main Length field, and it disables Force instrumental; put instrumental directions in the relevant sections. The plan takes the place of the plain prompt during generation. The editor is unavailable for Music v1.

Results And Credit Usage

When Save generated lyrics and details is enabled in Preferences, each successful track gets its own details file under Lyrics, such as Lyrics\Song_v1.details.json. It records the information returned by ElevenLabs. If that information includes a composition plan, use Open plan or details to load and edit it for another generation. A details file without a reusable plan cannot be opened as a plan. If ElevenLabs returns lyric lines, Lyrics\Song_v1.txt is saved for that variation. If WAV and MP3 audio share the same name, these files keep the audio extension to avoid a name collision. Audio and the shared prompt stay in the chosen music folder. These are returned lyrics, not a transcript of the recording. Turn this setting off to skip lyric and details files; title-named batches still need their small resume record.

The status log shows the elapsed time for the batch and the generation time for each completed track on a separate line. These are processing times, not audio playing lengths. ElevenLabs does not report a reliable credit charge for each request; use ElevenLabs Usage Analytics to check actual consumption. The same page opens from Help, Usage Analytics. A failed or cancelled request may still affect usage.

Choose Check Balance in the main window or Help menu, or press Ctrl+B, to read the included subscription credits remaining and the next reset in your computer's local time. This read-only subscription request does not generate audio or spend credits. The amount is the period limit minus credits used, not the charge for the last generation or a guarantee that a separately capped API key can spend all of it. Usage-based overages may permit more. If a restricted key cannot read subscription details, the check reports an error; music and sound-effects generation are unaffected.

Prompt Drafts

Music and Sound FX prompts are saved together in User\Prompt drafts.json after editing and when the application closes. Each mode restores its own unfinished text, including after restarting the app. This draft file is application data, not a reusable generation prompt. The first manual Save Prompt opens the Save dialog in the music output folder selected in Preferences. Later saves update the chosen file; Save As starts in the current music output folder.

Cancellation And Failure

Cancel stops the active request and removes incomplete temporary files. Variations completed before cancellation or a later failure are kept. A track appears in the chosen folder only when it is complete. If downloaded audio cannot be processed, the data is kept beside the intended output so it is not lost.

Updates

Update checks are available from Help and can be scheduled in Preferences. New installations check when the app starts; existing update preferences are kept. You can change the schedule or turn checks off. An install requires a ZIP and a valid matching signature; unsigned or invalid packages are not installed. Update checks require an internet connection and may report that no release is available.

Use Project Page to open the GitHub project page in your browser. More of Andre Louis's applications are listed on the Software page.

Files and Storage

ElevenLabsMusicGenerator.ini contains preferences. The Music folder is the default output. Generated audio and shared prompts use the chosen output folder; returned details, lyrics, and title-naming batch records use its Lyrics subfolder. The User folder contains the protected API key, prompt and plan drafts, and logs. Keep your music and User folder private when sharing the application.
