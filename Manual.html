ElevenLabs Music Generator

ElevenLabs Music Generator is a portable Windows application for creating music from a written prompt through the ElevenLabs Music API.

First Run

  1. Open Options, Preferences.
  2. Select the API key tab and enter your ElevenLabs API key.
  3. Use Test API key to verify it without generating music or spending credits.
  4. On the General tab, choose the default output folder, duration, variations, format, and model.

On a new portable installation, the application creates a Music folder beside the executable and uses it by default. This location remains relative when you move the application. A custom output folder can be chosen only in Preferences; existing installations keep their saved choice.

The key is stored as plain text in User\ApiKey.txt to preserve portability. Keep that file private and do not include the User folder when sharing the application.

Generating Music

  1. Write or paste a prompt into the standard multiline Prompt field.
  2. Choose the length, number of variations, and whether the result must be instrumental.
  3. Review the automatically suggested base filename. The output folder is the one saved in Preferences.
  4. Press Generate or Ctrl+Enter.
  5. Review the confirmation carefully. Generation starts only after you confirm that ElevenLabs credits will be spent.

Each generation saves one text file containing the input prompt. When generating multiple variations, the audio files use suffixes such as _v1 and _v2, but they share one unsuffixed prompt file. It does not contain lyrics generated by ElevenLabs.

When you move into a length or variations field, its current number is selected so that typing replaces it. Review the length and variation count in the confirmation dialog before spending credits.

If a batch was interrupted, Generate checks the existing tracks and offers to make only missing variations. The saved prompt must match, and existing WAV files must have the expected format and duration. An existing MP3's duration cannot be verified automatically, so review the confirmation carefully. If a check fails, choose a different base filename; existing tracks are never overwritten. Avoid changing the model or instrumental setting while resuming an older batch.

Prompt Drafts

The prompt is saved automatically to User\Prompt draft.txt after editing and when the application closes. It is restored on the next launch. The first manual Save Prompt opens the Save dialog in the music output folder selected in Preferences. Later saves update the chosen file; Save As starts in the current music output folder.

Cancellation And Failure

Cancel stops the active request and removes incomplete temporary files. Variations completed before cancellation or a later failure are kept. Output is first written to temporary files beside the destination and moved into place only when complete.

Portable Files

ElevenLabsMusicGenerator.ini contains ordinary preferences. The Music folder is the default output on a new installation. Manually saved prompts and generated audio share the chosen output folder. The User folder contains the API key, prompt draft, and bounded diagnostic logs. Keep both folders private when sharing the application. The program does not use the registry or extract a runtime at startup.
