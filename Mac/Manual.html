Prerequisites And API Key

Requires macOS 14 or later, an internet connection, and an ElevenLabs account with access to the Music or Sound Effects API you plan to use and sufficient credits. Generation can spend credits.

  1. Sign in to ElevenLabs.
  2. Open API Keys under Developers. Create a key for this app and enable access to Music or Sound Effects as needed. To see your balance in the app, also enable the key's user_read permission (read access to user information). You can edit an existing key to grant this permission. You can set a credit limit as an extra safeguard.
  3. Copy the key when it is first shown; the full value may not be visible later.

The key is stored in this Mac user's Keychain, not in the application folder, preferences, a prompt, or a log. Do not include a real key in a bug report or share it with another person. ElevenLabs explains key creation and restrictions in its API key guide.

First Run

  1. Open ElevenLabs Music Generator, Settings.
  2. On the API Key tab, paste your key, choose Save Key, then Test Key. Music testing does not generate audio. Sound Effects testing asks before generating a disposable 0.5-second effect that may spend credits. A result dialog opens with a focused read-only field so you can read or copy each result, including whether the key can read your credit balance. Press Escape or choose Close to return to Settings.
  3. Before generating, set your preferred Music folder on the General tab. Also choose whether to save returned lyrics and details.

If you leave the folder unchanged, the app saves to ~/Music/ElevenLabs Music Generator. The first save creates the selected folder if it does not already exist.

Generating Music

  1. Type or paste a prompt in the main window.
  2. Choose the model, output format, duration, variation count, and whether to force instrumental output.
  3. Review the suggested Base filename. It updates with the prompt until you edit the name yourself; New Prompt restores automatic naming. Spaces are kept. Clear the field to use each variation's title returned by ElevenLabs; the prompt is used if no title is returned.
  4. Use Generate or Command-Return. Review the confirmation: it states the number and length of new requests and warns that credits may be spent.

Prompt mode saves one shared text file containing your input prompt. Variations use suffixes such as _v1 and _v2. The shared prompt file is not a transcription of what was sung.

When the base filename is blank, each completed music variation uses the title returned by ElevenLabs and a two-digit sequence prefix, such as 01 - Song title.wav. The _v1 suffix is not used for returned titles. The app stores a small .titles.json batch record under Lyrics so an interrupted batch can resume without paying for completed tracks again. Keep this record with the audio and shared prompt. Title naming uses the detailed response even when saving lyrics and details is turned off.

If a batch stops, Generate checks the saved prompt or plan and existing audio, then offers to make only missing variations. WAV length and format are checked during resumption. MP3 duration cannot be verified automatically, so inspect existing MP3 tracks before confirming. Existing tracks are never overwritten. If a check fails, choose a different Base filename.

Generating Sound Effects

In the main window, choose Sound Effects v2 from Model. Enter a sound description of up to 450 characters, choose a base filename and variations, then Generate. Enable Sound Effects access for your API key on ElevenLabs. In Settings, Test Key checks the selected feature. For Sound Effects, it first asks permission to generate and discard a 0.5-second test effect, which may spend credits. Cancel is the default choice. The separate read-only balance check reports whether user_read is enabled, even if the feature test fails; missing balance access does not mean generation access failed. For Music v1, the non-generating test uses a v2.5 plan request and cannot confirm v1 directly.

Automatic duration lets the service choose the length. Turn it off to enter 0.5 to 30 seconds. Loop requests a seamless loop. Prompt influence ranges from 0 to 1; a higher value follows your wording more closely. Sound Effects supports the app's 44.1 kHz WAV and MP3 formats. Music-only options are unavailable in this mode; switching back restores the music controls.

The live window title shows characters used and the active limit; the prompt counter also shows characters remaining. Typing or pasting stops at the active model's limit: 450 characters for Sound Effects, 4,100 for Music. If you switch from a longer Music prompt to Sound Effects, the full Music draft is kept separately and restored when you return to Music.

Sound effects use the same output folder as music. Each batch saves one .sfx.json containing the prompt and its settings, without lyrics files. Choose Open Prompt to reuse this file; change the base filename for a new batch. Save Prompt still saves an ordinary text copy. Resuming an interrupted batch requires matching sound-effect settings and keeps completed audio. See the Sound Effects API reference for service details.

Composition Plans And Lyrics

Music v2 and v2.5 can use a section-based plan. Open Edit Plan or press Command-P to prepare one even when Use composition plan is off. Enable that checkbox when you want generation to use the plan. Each section has a heading, duration in milliseconds, optional lyric lines or musical cues, included/excluded styles, and context adherence. Use Open Plan or Details to load a saved plan or a track's details file when it contains a reusable plan. Export Plan saves the plan as a JSON file.

Open Prompt also recognizes .plan.json and reusable .details.json files and opens their sections in the plan editor. Saved JSON is laid out over several lines for reading outside the app. Within a quoted JSON value, \n is the required representation of a lyric line break; it becomes a real line break when the plan is imported.

Suggest from Prompt asks ElevenLabs for a draft plan; review it before generation. Plan mode uses section durations instead of the main Length setting. It follows the plan rather than the plain prompt, and Force instrumental is unavailable. The current plan is restored when you reopen the app.

A section heading such as Verse is sent with lyric lines as [Verse] followed by your text. You can also enter a short musical direction instead of lyrics. Suggestions are drafts, not a guarantee that every sung word will match. Plan requests are available for Music v2 and v2.5, not v1.

Results And Credit Usage

The Status log in the main window lists request progress and each completed track on a separate line with its generation time, not its audio playing length. Successful completion updates the log without an OK dialog. The music response does not provide a reliable per-request credit charge, so check ElevenLabs Usage Analytics for actual credit consumption. The same page opens from Help, Usage Analytics. A failed or cancelled request may still affect usage.

Balance refreshes when the app opens and after generation. Press Command-R to refresh it or Command-B to focus it. It shows your included allowance, next reset, and any overage reported by ElevenLabs. Zero included credits can still allow paid overages or Pay As You Go. This read-only check does not spend credits, but cannot show your total spendable balance, an API-key limit, or the cost of a single generation. See your subscription for billing details. A restricted key needs user_read to show Balance; generation can still work without it.

When Save returned lyrics and details is enabled in Settings, each variation gets a .details.json file in Lyrics with information returned by ElevenLabs. If it contains a composition plan, Open Plan or Details loads it for editing and another generation. A details file without a reusable plan cannot be opened as a plan. A text file is saved there only when ElevenLabs returns lyric lines. These are returned lyrics, not a transcript of the recording. Turn this setting off to skip lyric and details files; title-named batches still need their small resume record.

PCM output is wrapped as 44.1 kHz stereo WAV. MP3 options include 44.1 kHz and 48 kHz; availability depends on your account and the API. If the service rejects a format, the app displays its error. The app does not offer 48 kHz PCM.

Prompt Drafts

Music and Sound FX prompts are saved together in Prompt Drafts.json in this app's Application Support folder. Each mode restores its own unfinished text after restarting the app. This draft file is application data, not a reusable generation prompt. Command-S saves the current prompt as an ordinary text document; Command-Shift-S chooses a new name. This is independent of the shared prompt file saved during generation.

Cancellation And Failure

Successful generation updates Status Log without a success dialog. Enable Play a completion sound on the Audio tab in Settings if you want a short signal. It is off by default. When automatic playback is enabled, the new recordings play instead of the signal.

Cancel stops the active request and removes incomplete temporary files. Variations completed before cancellation or a later failure are kept. Existing tracks are never overwritten.

On the Audio tab of Settings, choose the playback device and default output format, and optionally enable Play new generations automatically in sequence. This is off by default. Only new audio from a successfully completed batch plays, one file at a time; existing tracks kept during resumption are not replayed. Cancelled or failed batches do not start playback automatically. Stop ends the current audio and the whole queue. Manually playing a result replaces the queue; changing the device stops it. Controls, Audio Settings opens this same Audio tab.

Completed results also appear in the Generated audio list for manual playback. Press F1 for brief help about the focused control, including controls in Settings and the plan editor. Read the explanation a line at a time; Close or Escape returns to the previous control. Open Manual opens the full guide.

Updates

Check for Updates is in the application menu. The app also checks when it opens unless you turn this off on the General tab of Settings. A newer release offers Install, Version History, and Later. Install downloads the package for this Mac's processor, verifies the signed and notarized app, then quits, replaces itself, and reopens. The previous app is restored if replacement fails. Your settings, API key in Keychain, prompts, and generated audio are not replaced.

Install updates silently is off by default. If you enable it in Settings, an update found at startup installs without another prompt; the app closes and reopens when the verified download is ready. Manual update checks still ask before installing. The Mac and Windows downloads are separate. If you prefer to install by hand, choose Version History and download only from the project's official releases page.

The project page shortcut opens the GitHub project page. The command is also available in the Help menu. More of Andre Louis's applications are listed on the Software page.

Files and Storage

Generated audio and one shared prompt or plan file are saved in the selected Music folder. Optional returned lyrics, generation metadata, and title-naming batch records go into its Lyrics subfolder. Settings and prompt or plan drafts live in this user's Application Support folder; the API key remains in Keychain. Keep generated music and account data private when sharing files from the app.
